# X-Plane Aircraft Tooling

Reusable skills, test harnesses, and workflows for developing and measuring X-Plane aircraft modifications against published POH data.

## Contents

- [`skills/test-xplane-aircraft`](skills/test-xplane-aircraft): Codex skill for repeatable climb, cruise, stall, takeoff, and landing performance testing.
- [`skills/develop-xplane-aircraft-mod`](skills/develop-xplane-aircraft-mod): Codex skill for reversible ACF/plugin development, POH surface calibration, lifecycle safety, and native X1000 integration.

Additional aircraft-specific harnesses, calibration data, and reporting tools can be added alongside the skills as the project grows.
