# X-Plane Flight Testing

Reusable tools, test harnesses, and workflows for measuring X-Plane aircraft performance against published POH data.

## Contents

- [`skills/test-xplane-aircraft`](skills/test-xplane-aircraft): Codex skill for repeatable climb, cruise, stall, takeoff, and landing performance testing.

Additional aircraft-specific harnesses, calibration data, and reporting tools can be added alongside the skill as the project grows.
